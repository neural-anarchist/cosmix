Waves · Elasticity · Musical acoustics

Strings

The textbook string is perfectly flexible, uniformly tensioned and moves only infinitesimally. A real musical string is none of those things. Four models are built here on the same set of physical parameters, so you can ask a sharper question than “does it vibrate?” — namely which departure from the ideal string is large enough to hear, for the string you have actually described.

Section three

From Ideal Waves to Real Strings

Where each model comes from, what it assumes, and where it stops being trustworthy.

1 · Standing waves and boundary conditions

Take a uniform string of length $L$ (metres), stretched to tension $T$ (newtons), with mass per unit length $\mu$ (kilograms per metre). Write $y(x,t)$ for the transverse displacement at distance $x$ along the string at time $t$. If the string is perfectly flexible and the displacement is small, Newton's second law applied to a short element gives the wave equation

$$\frac{\partial^2 y}{\partial t^2} = \frac{T}{\mu}\,\frac{\partial^2 y}{\partial x^2} \;\equiv\; v^2\,\frac{\partial^2 y}{\partial x^2}, \qquad v = \sqrt{\frac{T}{\mu}}$$

so disturbances run along the string at speed $v$ regardless of their shape. The string is clamped at both ends, which is a boundary condition on every solution:

$$y(0,t) = y(L,t) = 0 \quad \text{for all } t$$

A single travelling wave cannot satisfy that. A pair running in opposite directions can. Adding $A\sin(kx-\omega t)$ and $A\sin(kx+\omega t)$, where $k = 2\pi/\lambda$ is the wavenumber and $\omega = 2\pi f$ the angular frequency, gives

$$A\sin(kx-\omega t) + A\sin(kx+\omega t) = 2A\sin(kx)\cos(\omega t)$$

The $x$ and $t$ dependence has separated. The shape $\sin(kx)$ no longer moves; only its overall height breathes, at frequency $f$. This is a standing wave, and it is what the ideal model draws: the two faint travelling components and the bright resultant they add up to.

The left-hand clamp is satisfied automatically. The right-hand clamp demands $\sin(kL) = 0$, so $kL$ must be a whole multiple of $\pi$:

$$k_n = \frac{n\pi}{L}, \qquad \lambda_n = \frac{2L}{n}, \qquad n = 1, 2, 3, \dots$$

Exactly $n$ half-wavelengths fit between the clamps — that is the entire quantisation story, and it is geometric rather than quantum-mechanical. Since $f = v/\lambda$,

$$f_n = \frac{n}{2L}\sqrt{\frac{T}{\mu}}$$

with the corresponding motion

$$y_n(x,t) = A\sin\!\left(\frac{n\pi x}{L}\right)\cos(2\pi f_n t + \varphi)$$

Points where $\sin(n\pi x/L) = 0$ never move at all: these are the nodes, at $x = 0,\ L/n,\ 2L/n,\ \dots,\ L$, so mode $n$ has $n+1$ of them counting both clamps. Halfway between each pair the sine reaches $\pm 1$ and the string swings furthest: those $n$ points are the antinodes. The integer $n$ is the harmonic number, and because $f_n = n f_1$ exactly, the ideal string's overtones form a perfect harmonic series.

Assumptions, stated plainly. The string is perfectly flexible — it resists stretching but not bending. Displacements are small enough that the slope $\partial y/\partial x$ is much less than 1, so the length and therefore the tension are effectively unchanged by the motion. The tension is uniform along the string, and so is the linear density. The three models that follow each remove one of these assumptions.

2 · Why fretting changes pitch

Western instruments divide the octave into twelve equal steps, so adjacent semitones differ by a frequency ratio of $2^{1/12} \approx 1.05946$. Since $f_n \propto 1/L$ at fixed tension, raising the pitch by $f$ semitones means shortening the string by that same ratio, and a fret placed a distance $x_f$ from the nut leaves a speaking length $L_{\text{scale}} - x_f$. Setting $L_{\text{scale}}/(L_{\text{scale}}-x_f) = 2^{f/12}$ gives the standard rule

$$x_f = L_{\text{scale}}\left(1 - 2^{-f/12}\right), \qquad L_{\text{vib}} = L_{\text{scale}}\,2^{-f/12}$$

where $L_{\text{scale}}$ is the nut-to-bridge distance and $f$ the fret number. Note what this implies: if nothing but the length changed, fretting would be exactly in tune, by construction. Every deviation the model reports therefore comes from something else — and the dominant something else is tension.

Pressing the string down to the fret bends it out of the straight line it rested on. Because both ends are anchored, a longer path means a stretched string, and a stretched string pulls harder. The simulation computes that path explicitly rather than assuming a tension increase. Writing $y$ for height above the fingerboard, the resting string is the straight line from the nut, at height $h_{\text{nut}}$, to the saddle; the action $a$ at the chosen fret fixes the string's height there at $h_{\text{fret}} + a$, where $h_{\text{fret}}$ is the height of the fret crown. Fretted, the string runs in three straight segments: from the nut down to the finger contact at a distance $\delta$ behind the fret, over the crown, and on to the saddle. Their total, minus the resting length, is the extension $\Delta L$.

A string of cross-sectional area $A$ and Young's modulus $E$ stretched by $\Delta L$ from an original length $L_0$ carries an extra tension

$$\Delta T \approx \frac{EA}{L_0}\,\Delta L$$

which is Hooke's law written for a rod. This page uses $L_0 = L_{\text{scale}}$, the full speaking length, and $A$ is the area of the load-bearing core — on a wound string the winding contributes mass but negligible axial stiffness. Both conventions are worth stating because both matter: a real string is anchored beyond the nut and beyond the bridge, so the length actually free to stretch is longer than $L_{\text{scale}}$ and the true $\Delta T$ is correspondingly smaller. Taking $L_0 = L_{\text{scale}}$ makes this model an upper bound.

The fretted note is then the ideal-string prediction with both changes applied — the shorter length raises the pitch as intended, and the extra tension raises it further:

$$f = \frac{1}{2L_{\text{vib}}}\sqrt{\frac{T_0 + \Delta T}{\mu}}$$

Comparing that with the equal-tempered target $f_{\text{target}} = f_{\text{open}}\,2^{f/12}$, the error is measured in cents, hundredths of a semitone, so that 1200 cents is an octave:

$$\Delta c = 1200\,\log_2\!\left(\frac{f}{f_{\text{target}}}\right) = 600\,\log_2\!\left(1 + \frac{\Delta T}{T_0}\right)$$

The second form follows because the length factors cancel exactly, and it is worth reading twice: under this model the whole intonation error of a fretted note is a statement about the fractional tension rise, and nothing else.

Limitations. This is an idealised side view. It treats the string as three straight segments and the fingerboard as flat, ignoring neck relief, the curvature of the crown, and the width and softness of the fingertip. It assumes the string tension equalises along the whole path, whereas friction at the crown lets the speaking side and the nut side hold different tensions — which pushes the true shift below the value reported here. It ignores the winding structure of a wound string, any deformation of neck or body under the added load, and the string's own bending resistance near the contact points. It is a model of the leading geometric effect, not a complete account of a real instrument.

3 · Why real overtones are inharmonic

A perfectly flexible string resists being stretched but not being bent. A real wire does both: curving it stores elastic energy in the material, which adds a restoring term to the wave equation proportional to the fourth spatial derivative,

$$\mu\,\frac{\partial^2 y}{\partial t^2} = T\,\frac{\partial^2 y}{\partial x^2} - E I\,\frac{\partial^4 y}{\partial x^4}$$

where $I = \pi r^4/4$ is the second moment of area of a circular cross-section of radius $r$. Bending stiffness costs more energy for sharper curvature, and higher modes are more sharply curved — mode $n$ has $n$ times the wavenumber — so the stiffness term penalises the high partials most and pushes them sharp. Working through the substitution $y \propto \sin(n\pi x/L)$ gives partials at

$$f_n = n f_1 \sqrt{1 + B n^2}$$

with $f_1$ the ideal fundamental of the same string, and an inharmonicity coefficient that for a uniform circular string is

$$B = \frac{\pi^3 E r^4}{4\,T\,L^2}$$

which is dimensionless, as it must be: $[\mathrm{N\,m^{-2}}][\mathrm{m^4}] / ([\mathrm{N}][\mathrm{m^2}])$ cancels completely. Read the four dependences one at a time. $B$ grows with $E$, because a stiffer material resists bending more. It grows as the fourth power of the radius, which is why $B$ is by far the most sensitive to gauge — doubling the diameter multiplies the inharmonicity sixteenfold. It falls with tension, because a tighter string is dominated by the tension restoring force and the bending term matters relatively less. And it falls with the square of the length, because a long string is gently curved everywhere.

Together these explain a fact every instrument maker knows: short, thick strings under modest tension are strongly inharmonic, which is why the bass strings of a small piano are audibly stretched in their overtones and why piano tuners deliberately tune octaves wide. Long, thin, tightly strung wires are nearly harmonic. Try the four presets in the motion card to see the coefficient swing over two orders of magnitude.

Because $f_n$ is no longer an integer multiple of $f_1$, the partials no longer share a common period, and a superposition of them never exactly repeats. The superposition view makes this visible: the waveform drifts rather than closing on itself, and the fixed nodes of a single mode are gone — which is why the simulation stops drawing node markers as soon as more than one partial is present.

Limitations. The expression above is the standard approximation for a uniform circular wire with simply supported ends and small $B$; genuinely clamped ends shift the partials slightly further. A wound string is not a uniform cylinder at all — the winding adds mass without adding much stiffness, so this page evaluates $r$ from the load-bearing core while keeping the full $\mu$. That captures the right physics but the effective core radius of a real wound string is a fitted quantity, not a measured one.

4 · Large-amplitude motion and dynamic tension

The wave equation of Section 1 assumed the tension is constant. That is only true while the string's length is effectively constant, and a displaced string is longer than a straight one. For a curve $y(x)$ with a small slope, the arc length exceeds the base length by

$$\int_0^L\!\left(\sqrt{1 + \left(\frac{\partial y}{\partial x}\right)^2} - 1\right)dx \;\approx\; \Delta L_{\text{dyn}} = \frac{1}{2}\int_0^L \left(\frac{\partial y}{\partial x}\right)^{\!2} dx$$

using $\sqrt{1+u}\approx 1+u/2$. Because the displacement oscillates, so does this extra length, and with it the tension:

$$T(t) \approx T_0 + \frac{EA}{L}\,\Delta L_{\text{dyn}}(t), \qquad f(t) \approx \frac{1}{2L}\sqrt{\frac{T(t)}{\mu}}$$

The simulation does not integrate this numerically. It starts from a triangular pluck — the string pulled to a height $a$ at a fraction $p$ of its length and released from rest, which is a good description of a plectrum or fingertip leaving the string — and decomposes that shape into normal modes by Fourier analysis. With $x_0 = pL$,

$$A_n = \frac{2aL^2}{\pi^2 n^2\, x_0 (L-x_0)}\,\sin\!\left(\frac{n\pi x_0}{L}\right)$$

Two things follow immediately. The amplitudes fall as $1/n^2$, so a pluck excites a whole spectrum at once rather than a single harmonic. And any mode with a node at the plucking point gets $A_n = 0$: plucking at exactly $L/5$ silences the fifth partial and every multiple of it, which is why plucking position is a tone control on every stringed instrument.

Writing the motion as $y(x,t) = \sum_n a_n(t)\sin(n\pi x/L)$ with $a_n(t) = A_n e^{-\gamma t}\cos(2\pi f_n t)$, the integral above can be done in closed form, because the mode shapes are orthogonal and every cross term integrates to zero:

$$\Delta L_{\text{dyn}}(t) = \frac{\pi^2}{4L}\sum_n n^2 a_n(t)^2$$

This is exact for the modal sum and costs a few dozen multiplications, so the tension can be evaluated every frame without any numerical quadrature. As the number of modes grows it converges on the exact extra length of the triangle, $a^2/2x_0 + a^2/2(L-x_0)$, which is a useful check that the decomposition is right.

It converges slowly, though. Each term carries a factor $n^2 A_n^2 \propto 1/n^2$, so a sum truncated at $N$ modes falls short by roughly $0.6/N$ — about one per cent for the sixty-four modes used here. That shortfall is not purely a numerical compromise: a perfect corner is already unphysical, since a real plectrum or fingertip has width and leaves the string rounded, suppressing exactly the high modes being dropped.

Each $a_n(t)^2$ carries a factor $\cos^2(2\pi f_n t)$, so the tension pulses at twice each partial's frequency and never goes below $T_0$ — the string is always longer than its rest length, never shorter. Averaged over a cycle, $\langle\cos^2\rangle = \tfrac12$, so the sustained part of the shift is half the instantaneous peak. That cycle-averaged shift is what the plot draws and what the ear hears as pitch: it is largest immediately after the pluck and decays as the amplitude does, at twice the amplitude's decay rate because the effect goes as the square of the displacement. The audible result is a short downward pitch glide after a hard attack, settling to the nominal pitch as the note dies away.

This is an approximate, reduced model, not a nonlinear solution. A full treatment couples the modes to one another through the shared tension, transfers energy between them, and admits transverse–longitudinal coupling and whirling motion. Here the mode shapes and frequencies are held fixed at their small-amplitude values and the computed tension is used only to report a predicted frequency, never fed back into the motion. The small-slope expansion also requires $a \ll L$, which is comfortably satisfied at the millimetre amplitudes offered here but would fail for a violently displaced string. Damping is modelled as a single exponential rate applied equally to all modes; real strings lose their high partials faster than their low ones.

Section four

What Can Be Measured

Nothing on this page is data. Every number is a prediction from stated assumptions, and the interesting work begins where those predictions meet a real instrument.

5 · Testing these predictions

The three effects modelled here are all within reach of ordinary equipment, because they are all frequency measurements and frequency is the easiest quantity in physics to measure precisely.

Fretting. Record the open string and then the same string fretted, using a chromatic tuner that reads cents or an audio analyser. Tune the open string carefully first, since the prediction is a deviation from the equal-tempered target and an out-of-tune reference contaminates every reading. Compare the measured deviation with the model's, then repeat up the neck: the predicted curve along the fretboard has a distinctive shape, and matching that shape is far stronger evidence than matching a single number.

Inharmonicity. Record a plucked note and take an FFT. Read off the peak frequencies of the first ten or so partials — a long window gives finer frequency resolution, so record a sustained decay rather than the attack. Divide each measured partial by $n$ and by the fundamental: for a harmonic string the result is 1 for every partial, and the departure from 1 grows as $n^2$. Fitting $f_n/(n f_1) = \sqrt{1+Bn^2}$ to those points recovers $B$ directly, which can then be compared with $\pi^3 E r^4/4TL^2$.

Amplitude. Pluck the same string gently and hard, and track the pitch against time rather than reading a single value — most analysis software will plot a fundamental-frequency track. The prediction is a short sharp transient decaying to a steady pitch, with the initial offset scaling as the square of the pluck amplitude. That square law is the sharpest test available: doubling the displacement should roughly quadruple the initial shift.

Change one variable at a time. Fret number, string gauge, action height, plucking amplitude and plucking position each appear in a different place in the equations, so varying them one at a time separates effects that a single measurement would confound. Raising the action changes the fretting shift but leaves inharmonicity untouched; changing gauge moves both, and moves inharmonicity far more.

Fit the uncertain parameters; do not trust the defaults. Several inputs on this page are known only approximately for any real string. The effective core radius of a wound string, the effective length free to stretch, the true Young's modulus of a drawn and wound wire, and how far a particular player pushes the string past the crown are all quantities to fit from measurements, not to read off a slider. The right way to use this simulator is to fix everything that can be measured directly — scale length, fret positions, diameter, tension, action — and then see whether one consistent choice of the remaining parameters reproduces several independent measurements at once. A model that matches one number is fitted; a model that matches a curve is tested.
