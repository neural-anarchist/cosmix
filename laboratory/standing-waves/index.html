03 — Theory

Four departures from the ideal string

Each model begins with the same wave equation and relaxes one assumption.

1 · Fixed ends select the harmonics

For a uniform string under tension \(T\), with linear density \(\mu\), small transverse displacements \(y(x,t)\) obey

\[ \frac{\partial^2 y}{\partial t^2}=\frac{T}{\mu}\frac{\partial^2 y}{\partial x^2}, \qquad v=\sqrt{\frac{T}{\mu}}. \]

Fixed ends require \(y(0,t)=y(L,t)=0\). Only shapes with nodes at both ends survive:

\[ y_n(x,t)=A\sin\!\left(\frac{n\pi x}{L}\right)\cos(2\pi f_n t), \qquad f_n=\frac{n}{2L}\sqrt{\frac{T}{\mu}}. \]

The integer \(n\) counts half-wavelengths along the string. Mode \(n\) has \(n+1\) nodes, including the clamps, and \(n\) antinodes. Because \(f_n=nf_1\), the ideal string has a perfectly harmonic spectrum.

Assumptions. The string is flexible, uniform, and lightly displaced. Its tension does not change during the motion.

2 · A fret shortens — and stretches — the string

Equal-tempered frets place the vibrating length at

\[ L_{\mathrm{vib}}=L_{\mathrm{scale}}2^{-f/12}, \]

where \(f\) is the fret number and \(L_{\mathrm{scale}}\) is the nut-to-bridge distance. If tension stayed fixed, that change alone would produce the intended semitone interval. In practice, the finger first pulls the string below the fret crown. The total path becomes slightly longer, so the tension rises.

For a string with load-bearing area \(A\) and Young’s modulus \(E\), a small extension \(\Delta L\) gives

\[ \Delta T=\frac{EA}{L_0}\Delta L. \]

The simulation finds \(\Delta L\) from the side-view geometry: nut to finger, finger to fret, and fret to bridge. It then uses the shorter vibrating length and the higher tension to predict the note. With ideal fret placement, the residual error, in cents, is set by the tension increase:

\[ \Delta c=600\log_2\!\left(1+\frac{\Delta T}{T_0}\right). \]

Scope. This is a geometric upper-bound model. It ignores friction at the fret, neck relief, and the string length beyond the nut and bridge.

3 · Bending stiffness spreads the partials

A real wire resists curvature as well as tension. The additional bending term raises the high partials because they have the shortest spatial wavelength. A standard approximation is

\[ f_n=nf_1\sqrt{1+Bn^2}, \qquad B=\frac{\pi^3Er^4}{4TL^2}. \]

Here \(r\) is the load-bearing radius. The fourth power is the important feature: a modest increase in diameter can greatly increase inharmonicity. Higher tension and longer scale length reduce it.

The fundamental shifts very little. The larger effect is spectral: upper partials are sharp relative to exact harmonics, which changes timbre and makes wide piano octaves necessary.

Scope. The formula is most reliable for a uniform, slender wire and small \(B\). A wound string is represented by its core for stiffness and its full mass for \(\mu\).

4 · A hard pluck raises tension briefly

A curved string is longer than a straight string. For small slopes,

\[ \Delta L_{\mathrm{dyn}}\approx\frac12\int_0^L\left(\frac{\partial y}{\partial x}\right)^2dx. \]

The simulation releases a triangular pluck of height \(a\) and writes it as a sum of normal modes. If the pluck is at \(x_0=pL\), the modal amplitudes are

\[ A_n=\frac{2aL^2}{\pi^2n^2x_0(L-x_0)} \sin\!\left(\frac{n\pi x_0}{L}\right). \]

A pluck therefore excites many modes, while a mode with a node at the plucking point is absent. The extra length produces \(\Delta T=EA\,\Delta L_{\mathrm{dyn}}/L\), so pitch is highest immediately after release and falls as the vibration decays. Since the length correction scales as displacement squared, its average decay is twice as fast as the amplitude decay.

Scope. The small-slope approximation is best for modest plucks. The triangular release is an idealisation of a pick or fingertip.

04 — Measure

Testing the predictions

Every number here is a prediction. Each effect is a frequency shift, so a tuner or a spectrum analyser can check it.

Fretting. Tune the open string first, then record the string fretted at several positions with a tuner that reads cents. Compare the error along the neck with the predicted curve. Matching the shape is stronger evidence than matching one value.

Inharmonicity. Record a sustained note and take an FFT. For each of the first ten or so partials, divide the measured frequency by \(nf_1\). Fitting \(\sqrt{1+Bn^2}\) to those ratios gives \(B\), which you can compare with \(\pi^3Er^4/4TL^2\).

Pluck height. Pluck the same string softly and hard, and track the pitch against time. The initial shift should scale with the square of the pluck height: doubling the pluck should roughly quadruple it.

One variable at a time. Fret, gauge, action, pluck height, and pluck position enter the equations in different places. Raising the action changes the fretting shift but not the inharmonicity. Changing the gauge moves both, and moves the inharmonicity far more.

Fit the uncertain inputs. Some inputs are known only roughly for a real string: the core radius of a wound string, the length free to stretch, Young’s modulus, and how far a finger presses. Measure what you can (scale length, diameter, tension, action), then fit these few to several independent measurements. A model that matches one number has been tuned. A model that matches a curve has been tested.
