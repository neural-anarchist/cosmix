Model assumptions
  • Dipole axes are constrained to remain parallel in the laboratory frame. A freely rotating bar magnet would be a different system.
  • Bobs are point masses on massless rods.
  • Magnetic forces use a softened point-dipole potential. The softening length represents finite magnet size qualitatively; it is not calibrated to a particular magnet.
  • There is no aerodynamic coupling, pivot friction model, rod flexibility, or magnetic hysteresis.

The default 5 A·m² moment is illustrative, not derived from a specific magnet.

04 — Theory

From dipoles to normal modes

The nonlinear dynamics define the resting state. Linearizing around that state turns the system into a generalized eigenvalue problem.

Interaction and the magic angle

Pendulum $i$ has its pivot at $x=(i-1)d$, so its bob sits at $\mathbf{r}_i = \big((i-1)d + L\sin\theta_i,\, -L\cos\theta_i\big)$. Every dipole points along $\hat{\mathbf{s}}=(\cos\alpha,\sin\alpha)$, held fixed in the laboratory frame. For point dipoles, with $\mathbf{r}=\mathbf{r}_j-\mathbf{r}_i$,

$$U_{ij} = \frac{\mu_0\mu_i\mu_j}{4\pi}\,\frac{1 - 3(\hat{\mathbf{s}}\cdot\hat{\mathbf{r}})^2}{r^3}$$

With the bobs level, $\hat{\mathbf{s}}\cdot\hat{\mathbf{r}}=\cos\alpha$ and $U_{ij}\propto G(\alpha)/u_{ij}^3$, where

$$G(\alpha) = 1 - 3\cos^2\alpha, \qquad u_{ij} = (j-i)\,d + L(\theta_j-\theta_i)$$

$G=+1$ at $\alpha=90^\circ$: side-by-side dipoles repel. $G=-2$ at $\alpha=0^\circ$: head-to-tail dipoles attract. $G=0$ at $\alpha=\arccos(1/\sqrt3)\approx54.74^\circ$: the point-dipole coupling vanishes. The simulation softens $r\to\sqrt{r^2+\varepsilon^2}$ with $\varepsilon=0.03\,d$, so the residual there is small but not zero.

Show derivation

Expanding in the small gap change $\delta=L(\theta_j-\theta_i)$ about $D=(j-i)d$, with $C=\mu_0\mu_i\mu_j/4\pi$:

$$U_{ij} \approx \frac{CG}{D^3}\left[\,1 - \frac{3\delta}{D} + \frac{6\delta^2}{D^2}\,\right]$$

The linear term is a constant torque; the quadratic term is the coupling.

Resting configuration and nonlinear motion

Each bob is a point mass on a massless rod, so pendulum $i$ obeys

$$m_i L^2\,\ddot\theta_i = -m_i g L\sin\theta_i - b\,m_i L^2\,\dot\theta_i + \sum_{j\neq i}\tau_{ij}, \qquad \tau_{ij} = -\frac{\partial U_{ij}}{\partial\theta_i}$$

Every pair interacts, not only neighbours, but the coupling falls as $1/d^5$. The magnets exert a net torque even when the rods hang vertically, so $\theta=0$ is generally not an equilibrium. The resting state $\boldsymbol\theta^\ast$ solves

$$-m_i g L\sin\theta^\ast_i + \sum_{j\neq i}\tau_{ij}(\boldsymbol\theta^\ast) = 0$$

The page finds it by damped Newton iteration and expands about it.

The linear term of the previous section is a constant push or pull on each pair. It shifts the balance point, so the numerical $\boldsymbol\theta^\ast$ must be solved for rather than assumed. It changes the resting gap $u^\ast_{ij}$, and the coupling depends strongly on that gap.

Small-amplitude spring–mass model

Write $\eta_i=\theta_i-\theta^\ast_i$. Keeping first order in $\boldsymbol\eta$ gives

$$\mathbf{M}\ddot{\boldsymbol\eta} + \mathbf{K}\boldsymbol\eta = \mathbf{0}, \qquad M_{ij}=m_iL^2\delta_{ij}$$ $$K_{ii} = m_i g L\cos\theta^\ast_i + \sum_{j\neq i}\kappa_{ij} + \sigma_i,\qquad K_{ij}=-\kappa_{ij}$$

In spring language $x_i=L\eta_i$: gravity is a spring to ground and each pair is a spring of constant $\kappa_{ij}/L^2$. What is linearized: $\sin\theta$, the dipole energy to second order in the gap change, and the geometry about $\boldsymbol\theta^\ast$. Expect it to fail at large amplitude, for unstable or nearly soft modes, and when bobs approach closely.

Show derivation $$\kappa_{ij} = \frac{12\,\mu_0\,\mu_i\mu_j\,G(\alpha)\,L^2}{4\pi\,u_{ij}^{\ast\,5}} \quad\text{(point-dipole limit, resting gap } u^\ast_{ij}\text{)}$$ $$\sigma_i = \sum_{j\neq i}\operatorname{sgn}(j-i)\,\frac{3\,\mu_0\,\mu_i\mu_j\,L\,\sin 2\alpha}{4\pi\,u_{ij}^{\ast\,4}}$$

$\sigma_i$ is the tilt term. It shifts each pendulum's own restoring torque, does not couple the pendulums, and vanishes at $\alpha=0^\circ$ and $90^\circ$. The simulation computes $\mathbf{K}$ by differentiating the softened torque numerically, so it includes every pair.

Normal modes and the uniform-chain result

Substituting $\boldsymbol\eta=\mathbf{v}e^{i\omega t}$ gives the generalized eigenvalue problem

$$\mathbf{K}\mathbf{v}=\lambda\,\mathbf{M}\mathbf{v},\qquad \lambda=\omega^2, \qquad \mathbf{v}_k^{\mathsf T}\mathbf{M}\mathbf{v}_l=\delta_{kl}$$

A mode with $\lambda\le0$ is unstable. The closed form below is a comparison, not the solver, and needs all of these assumptions: equal masses, equal dipole moments, nearest-neighbour truncation, $\cos\theta^\ast\approx1$, and an orientation symmetric under left–right reflection ($\sin2\alpha=0$, so no tilt term).

$$\omega_k^2 = \frac{g}{L} + \frac{4\kappa}{mL^2}\sin^2\!\left(\frac{k\pi}{2N}\right), \quad v_k[i]=\cos\!\left(\frac{k\pi(i+\tfrac12)}{N}\right),\quad k=0,\dots,N-1$$

The uniform mode $k=0$ sits at $\sqrt{g/L}$ within this approximation. If $G<0$ the anti-phase mode is the soft one. The table above shows the gap between closed form and numerical modes.

Since $\mathbf{M}$ is diagonal and positive, $\mathbf{S}=\mathbf{M}^{-1/2}$ makes $\mathbf{A}=\mathbf{S}\mathbf{K}\mathbf{S}$ symmetric with the same eigenvalues. A Jacobi sweep diagonalizes it, and $\mathbf{v}=\mathbf{S}\mathbf{u}$. For the uniform nearest-neighbour chain $\mathbf{K}\approx mgL\,\mathbf{I}+\kappa\,\mathbf{L}_{\text{path}}$, whose Laplacian spectrum is $4\sin^2(k\pi/2N)$.
